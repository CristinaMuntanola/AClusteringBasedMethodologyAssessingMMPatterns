# AClusteringBasedMethodologyAssessingMMPatterns
This repository has been created as a supplement to showcase both the commented R programming code and the graphs generated from it. This code can be replicated by anyone who wishes to do so, however, it is requested that in any work using these scripts, the paper be cited. For inquiries, please contact Cristina Muntañola Valero, the main author of the paper.
This repository contains various numbered files. The number indicates the execution order of the scripts. If files share the same number, it means the code within them can be run independently of one another.
The HTML files are:
-The file numbered 1: descriptive results and Table 1 from the general database.
-Files numbered 2: these correspond to the clustering analyses performed for each technique to group the individuals.
-Files numbered 3: these correspond to analyses using the clusters generated in the previous section. They include logistic regressions for hospitalization, ICU admission, and death due to COVID-19; descriptive results of the K-Modes analyses; and Table 1 for each technique, comparing their respective clusters.
