We must now select the best of the fitted models. The Bayesian Information Criterion (BIC) and the Akaike Information Criterion (AIC) can be used for model selection, although they are not goodness-of-fit indices, as they do not provide interpretable information regarding the magnitude of the model-data fit.

-The AIC attempts to incorporate both the estimated residual variance and model complexity into a single statistic. It relies on an asymptotic approximation that may not hold true for a given finite dataset (see https://www.sciencedirect.com/topics/medicine-and-dentistry/akaike-information-criterion).

-The BIC favors more parsimonious models and is also based on the deviance information criterion (see https://www.sciencedirect.com/topics/social-sciences/bayesian-information-criterion). It is an alternative selection method to the AIC, possessing different asymptotic properties.

The difference between BIC and AIC becomes apparent when we add a set of k parameters (regressors and/or an intercept) to improve the model’s goodness of fit. In such cases, the BIC imposes a heavier penalty (compared to the AIC) on this increase in parameters.

Now, we will select the best model provided by the analysis and view the names of the final identified classes. You can compare the different solutions using BIC or AIC information criteria. BIC is preferred over AIC for latent class models, though both are generally used. A lower BIC value is better than a higher one. Along with AIC and BIC, you also obtain a Chi-square goodness-of-fit measure.

AIC does not correct for sample size, which can be quite problematic with larger samples. (See cAIC and aBIC below.)

A higher log-likelihood indicates a better model fit (unlike standard likelihood). llik: The maximum log-likelihood value of the estimated model.

Caution is required if the degrees of freedom are negative. According to the documentation by Lanza et al. (http://www.methodology.psu.edu/ra/lca/model-faq/), a model yields negative degrees of freedom when it attempts to estimate more parameters than is feasible. If you encounter negative degrees of freedom, reduce the number of latent classes or latent states, or impose parameter constraints to lower the number of parameters being estimated.

Avoid using AIC for LCA, as it performs poorly; instead, use cAIC, BIC, and aBIC. Lower values ​​for these indices indicate a better fit.

Pearson’s chi-square goodness-of-fit statistic for fitted versus observed multi-way tables. The goodness of fit of a specific latent class model to the observed data can be assessed using a chi-square test based on observed and expected frequencies. This test checks for independence between latent class membership and class membership. A drawback in our case is that the null hypothesis is highly likely to be rejected due to the large sample size.

Below, we implement a loop similar to the one in the primary LCA_common_synthax_FINAL script (the code immediately preceding this) to create character1, character2, char.freq1, and char.freq2. These objects help us distinguish between diseases within each cluster. Uses:

  • char.freq1: Created to determine if a variable is associated with a given cluster. It applies the criterion that a disease within a cluster must have an Observed/Expected (O/E) prevalence ratio of 2 or higher, and/or a cluster exclusivity of 25% or higher. This is generally the appropriate approach, as the authors specify that meeting either one of the two criteria suffices. It is a less restrictive criterion, since a disease is included in the cluster if it meets just one of the two conditions.

  • char.freq2: Similarly used to assess the relationship between a variable and the cluster, but in this case, the requirement is that diseases must meet both criteria rather than just one. Thus, they must have an O/E ratio ≥ 2 and exclusivity ≥ 25%. We calculate this as well.

Of course, other criteria may be used, or the values ​​of 2 and 25% can be modified in the code that follows.
